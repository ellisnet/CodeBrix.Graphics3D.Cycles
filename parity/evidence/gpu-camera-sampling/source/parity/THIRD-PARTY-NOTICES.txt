Changes: native closure casts replaced by typed WGSL records; SVM bytecode
access replaced by bounded storage-buffer indexing; the currently implemented
instruction/closure subset is explicitly limited and unsupported nodes return
an error. CPU reference functions are included from the clean upstream checkout.
The multi-bounce port adapts triangle barycentric position reconstruction,
self-intersection tests, ray offsets and path throughput updates. The ray-offset
method is attributed upstream to "A Fast and Robust Method for Avoiding
Self-Intersection", Ray Tracing Gems, chapter 6.
The camera/sampling port adapts static perspective rays, pixel filtering,
tabulated Sobol lookup and integer scrambling. Native reference execution
still includes the original upstream implementation without editing it.
