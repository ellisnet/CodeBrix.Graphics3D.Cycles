src/util/atomic.h. Compiler dependency files confirm this, including

2.0 release. Resolution requires an adequately licensed replacement or
explicit upstream licensing clarification; removing notices is not a fix.
Jeremy is handling this resolution. Development/rendering research continues
at his request. Do not describe the unresolved issue as resolved or silently
include these headers in an Apache-only vendor bundle.

The same checkout contains GPL-2.0-or-later-tagged build/maintenance files:

  tools/sync_blender_commits.py

Their presence is a separate source-vendoring consideration, not evidence
that each is compiled into the renderer. Avoid blindly copying the checkout.

1. CYCLES AND CODE ADAPTED THROUGH CYCLES
---------------------------------------
Source: https://github.com/blender/cycles
Official upstream: https://projects.blender.org/blender/cycles
Pinned revision: a456b761034dda42c32eef9f4aae0fa5a5c9f604
Local reference checkout: ~/ClaudeHome/cycles-webgpu-upstream

Cycles' default license is Apache-2.0, with per-file exceptions. The host
build compiles external source; the repository contains derived WGSL,
adapters, generated registration overlays, and source-based test harnesses.
The reference checkout is kept unchanged. Function translation, resource
access changes, supported subsets and file-level derivation lists are in:
  research/THIRD-PARTY-NOTICES.txt
  parity/THIRD-PARTY-NOTICES.txt
  native/THIRD-PARTY-NOTICES.txt
Historical evidence directories preserve the notices at each checkpoint;
this root inventory records later findings without rewriting that evidence.

Retain the per-file copyright notices, including Blender Foundation/Blender
Authors, NVIDIA Corporation, Intel Corporation and the contributors below.
Copies of Cycles' license texts are in third_party/licenses/Cycles-*.
The atomic-header exception above remains unresolved.

The native world-shader interpreter now additionally adapts the pinned SVM
bytecode dispatcher, node helpers, background shader setup and BSD-licensed
emission accumulation. Exact source files and modification descriptions are
listed in native/THIRD-PARTY-NOTICES.txt. No new external source repository or
runtime dependency was added for this extension. Its inverse-trigonometric
adapters are original CodeBrix contributions derived from mathematical series
and identities; they are not imported libc code.

The native triangle shader-data preparation additionally adapts Cycles'
geometry, transforms, compact differentials and packed-normal helpers. Those
Apache-2.0 files include Blender Foundation and Intel notices; their exact
derivation list is in native/THIRD-PARTY-NOTICES.txt. The portable GPU replay
harness is original CodeBrix test code using the existing shipped WebGPU
runtime; it adds no source repository or runtime dependency.

Additional licenses/attributions in the host/kernel source include:

* BSD-3-Clause: Open Shading Language-derived closures, emission, sampling,
  camera and SVM helpers; Sony Pictures Imageworks Inc., et al., and Blender
  Foundation. Source lineage: https://github.com/AcademySoftwareFoundation/OpenShadingLanguage
  These are the copies in the pinned Cycles revision, not a separately

  The existing WGSL subset's full BSD notice is in parity/licenses/BSD-3-Clause.txt.

* Zlib: src/util/md5.cpp and md5.h, Copyright 1999, 2002 Aladdin Enterprises.
* Sky models in third_party/sky: BSD-3-Clause (Lukas Hosek and Alexander
