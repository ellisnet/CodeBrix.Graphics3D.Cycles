Purpose. This is a test asset: the source of the bench oracle scenes
native/oracle/scenes/assets/bench_01.json and bench_01-hdri.json, which
native/oracle/scenes/make_bench_bundle.py generates from it with the glTF
example tool. The directory keeps the glTF document's relative layout
(bench_01.bin beside it, the images under ../Textures). It is not part of the
NuGet package payload.
